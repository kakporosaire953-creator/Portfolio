# 🚀 Démarrage Rapide

## ⚡ Déployer en 3 minutes

### Option 1: Vercel (Recommandé)
1. Aller sur https://vercel.com
2. "New Project" → Importer depuis GitHub
3. Cliquer "Deploy"
4. ✅ En ligne en 30 secondes !

### Option 2: Netlify
1. Aller sur https://netlify.com
2. "Add new site" → Import depuis GitHub
3. Deploy
4. ✅ Fait !

### Option 3: Local
```bash
git clone https://github.com/kakporosaire953-creator/Portfolio.git
cd Portfolio
python -m http.server 8000
# Ouvrir http://localhost:8000
```

## 🆘 Problèmes Courants

**Images ne s'affichent pas**
→ Vérifier que fichiers sont dans `/images`

**Menu mobile ne fonctionne pas**
→ Vider cache (Ctrl+F5)

**Site lent**
→ Compresser images avec TinyPNG

**Formulaire ne marche pas**
→ Configurer FormSpree ou Netlify Forms

## 🛠️ Commandes Utiles

### Terminal intégré
Cliquer sur l'icône terminal en bas à droite, puis taper :
- `help` - Voir toutes les commandes
- `about` - Informations sur vous
- `projects` - Liste des projets
- `skills` - Vos compétences
- `theme dark` - Passer en mode sombre
- `lang en` - Passer en anglais
- `clear` - Vider le terminal

### Assistant IA
Cliquer sur l'icône robot pour poser des questions :
- "Quels sont vos services ?"
- "Parlez-moi des projets"
- "Comment vous contacter ?"

## 🐛 Problèmes Courants

### Le menu mobile ne s'affiche pas
➡️ Vider le cache navigateur (Ctrl+F5)

### Les animations ne fonctionnent pas
➡️ Vérifier que `assets/scroll-animations.js` est chargé

### Les images ne s'affichent pas
➡️ Vérifier que les fichiers sont dans `/images`

### Le formulaire ne fonctionne pas
➡️ Normal ! Il faut configurer un backend (voir SEO-GUIDE.md)
